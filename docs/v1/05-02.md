## Fine-tuned LoRA ->  Ollama Built-in Chat

### Step 1: Merge LoRA weights into the base model (AutoDL)

Ollama doesn't load LoRA adapters directly — you need to merge them first, then convert to GGUF.

Use the repo script (reads **`configs/qlora_config.yaml`** for base model id, **`trust_remote_code`**, adapter path, and default merged output). This is the same **`PeftModel.from_pretrained` → `merge_and_unload()`** flow as in the Hugging Face PEFT docs — **there is no supported upstream `python -m peft merge` CLI** in standard **`peft`** installs; the old one-liner below was incorrect.

```bash
cd /root/autodl-tmp/jinyong-finetune   # your clone
python scripts/train/merge_lora.py --config configs/qlora_config.yaml
# Optional: --merged-dir ./outputs/jinyong-merged --dtype float16
```

See also **`docs/v1/autoDL.md`** and **`docs/v1/LORA_TO_GGUF_GUIDE.md`**.

### Step 2: SCP merged.zip AutoDL to Macbook Pro

`scp -P 46840 root@connect.cqa1.seetacloud.com:/root/autodl-tmp/jinyong-finetune/outputs/jinyong-merged.zip ~/Download/`

### Step 3: Convert merged model to GGUF

```bash
python ~/my-tools/llama.cpp/convert_hf_to_gguf.py ./outputs/jinyong-merged \
  --outfile models/jinyong-lora.gguf \
  --outtype f16
```

### Step 4: Quantize

```bash
LLAMA=~/my-tools/llama.cpp
SRC=~/models/jinyong-f16.gguf

# q4_k_m (recommended)
$LLAMA/llama-quantize $SRC ~/models/jinyong-q4.gguf q4_k_m

# Optional: also build q5_k_m if you want to compare quality
$LLAMA/llama-quantize $SRC ~/models/jinyong-q5.gguf q5_k_m

# Verify
ls -lh ~/models/jinyong-*.gguf

# Remove the 14 GB f16 intermediate
```

### Step 5: Create an Ollama Modelfile

```dockerfile
# Modelfile
FROM /models/jinyong-lora.gguf

SYSTEM """
You are a Jin Yong wuxia storyteller. You speak in classical Chinese martial arts novel style.
"""

PARAMETER temperature 0.8
PARAMETER num_ctx 4096
```

### Step 6: Register and run in Ollama

```bash
ollama create models/jinyong-lora -f models/Modelfile
ollama run jinyong-lora
```
